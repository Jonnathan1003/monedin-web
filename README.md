# Monedín 2: Aventura espacial (versión web)
Juego educativo sobre monedas chilenas, para aprender con pesos. Incluye la aventura 2D (Monedín 2) y el modo clásico (Monedín 1, con 3 preguntas por misión). Funciona sin internet tras la primera carga (PWA). No recopila datos.

Presentación de Pensamiento Matemático. Creado por: Livier Alarcón, Betsabe Belmar, María Venegas y Johanna Paredes.
